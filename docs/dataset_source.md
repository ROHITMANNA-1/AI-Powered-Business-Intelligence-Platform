# Dataset Source and Scope

## Selected source

- **Name:** Online Retail
- **Publisher:** UCI Machine Learning Repository
- **Creator:** Daqing Chen
- **DOI:** [10.24432/C5BW33](https://doi.org/10.24432/C5BW33)
- **Source page:** https://archive.ics.uci.edu/dataset/352/online+retail
- **License:** [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
- **Coverage:** UK non-store online retail transactions from 2010-12-01 through 2011-12-09

## Analytical scope

Available measures include line-item quantity, unit price, derived revenue, order count, customer count, product count, country mix, and time trends. Cancelled invoices and non-positive quantities/prices require explicit data-quality handling.

Unavailable in the source: profit, cost, product category, shipping mode, shipping cost, delivery date, and marketing channel. The application must label analyses requiring those fields as unsupported or request a different uploaded dataset.
