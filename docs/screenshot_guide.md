# Screenshot Guide

1. Start the app with `streamlit run app.py`.
2. Upload the UCI Online Retail workbook or a small CSV fixture.
3. Capture the Overview tab showing KPI cards and the Explore tab showing the revenue trend.
4. Capture the AI analyst tab with the generated SQL, result table, and grounded explanation.
5. Capture the Report tab with the Markdown preview and download controls.

Do not include API keys, local filesystem paths, private customer data, or database credentials in screenshots.
